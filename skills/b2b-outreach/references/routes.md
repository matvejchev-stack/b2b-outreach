# Как выйти на нужного человека

Читай для поиска ЛПР, рекомендаций, партнёров и запасных путей к важной компании.
Задача поиска: установить человека, его связь с нашей задачей и подходящий
рабочий канал. Один общий email не завершает исследование сильного кандидата.

## Карта выходов

| Путь | Где искать | Что проверить |
|---|---|---|
| Прямой рабочий контакт | Сайт компании, подразделения, официальные документы | Нынешнюю роль, площадку, источник именно этого адреса |
| Платный справочник | Для РФ: СБИС / Saby Profile при доступном тарифе | Нужные функции, актуальность, общий или личный рабочий контакт |
| Профильный отдел | Техническая служба, производство, инвестиции, закупки | Кто владеет задачей и кому может передать обращение |
| Существующие связи | Переданные базы, CRM, доступная переписка, сведения владельца | Кто уже ведёт отношения, были ли звонки, запреты и обещания |
| Рекомендация | Знакомый, клиент, отраслевой эксперт, участник делового события | Реальность связи и готовность представить; знакомство не выдумывать |
| Партнёрский путь | Интегратор, проектировщик, сервисная компания, дилер | Полномочия, конфликт каналов и роль в проекте |
| Профессиональные источники | Программа конференции, доклад, ассоциация, техническая статья | Дату, организацию, авторство и нынешнюю роль |
| Документы проекта | Закупка, техническое приложение, инвестпроект, разрешённый реестр | Актуальность проекта и назначение опубликованного контакта |
| Официальная маршрутизация | Приёмная, форма обратной связи, общий рабочий ящик | Пригодность канала для запроса ответственного |

Список участников выставки доказывает запись в списке, а не посещение
или знакомство. Автор статьи может уже работать в другом месте. Контакт
закупочной процедуры не становится универсальным рекламным адресом.
Порядок предложения платного доступа: [paid-sources.md](paid-sources.md).

## Последовательность поиска

1. Уточни предприятие, юридическое лицо, площадку и производственную задачу.
   Проверь переданную базу и историю отношений до обогащения контактов.
2. Сформулируй нужные роли на языке рынка: владелец задачи, техническая оценка,
   коммерческое решение. Установи персоналии доступными источниками.
3. Проверь официальный сайт и документы. Для пробела используй другие
   источники из карты; меняй запрос по должности, площадке, операции и фамилии.
4. Подтверди роль и канал отдельно. Старую публикацию оставь историческим
   свидетельством, если актуальность не установлена.
5. Сравни выходы по близости к задаче, доверию и существующему владельцу
   отношений. Назначь основной, резервный и причину выбора.

Для каждого пути сохраняй: человека/роль, источник и дату, рабочий канал,
владельца отношений, проверенные факты, неизвестные и следующее действие.
Важному кандидату дай разумную глубину поиска в пределах срока задачи.
Если новый проход не добавляет доказательств, зафиксируй покрытие и пробел,
выбери подтверждённый общий маршрут либо удержи обращение.

## Переход к сообщению

Найденный номер, рекомендация написать в мессенджер и имя знакомого сами
по себе не расширяют разрешения на внешнее сообщение. Подготовь текст
для выбранного канала и проверь действующие границы поручения. Запрос
представить отправляй только при разрешении на это действие.

В просьбе о рекомендации коротко объясни: почему нужна именно эта роль,
какой вопрос хотим обсудить и чем потенциально полезны. Не передавай
посреднику закрытые параметры сделки и лишние личные сведения.
После перенаправления проверь нового человека и канал; запиши связь
с исходным обращением. Перенаправление остаётся маршрутом, пока не возникла
подтверждённая задача и согласованный следующий шаг.
