# B2B-кампании для Codex и Claude Code

Автор: **Александр Матвейчев**. Версия комплекта: **0.2.0**.

Навык помогает разобрать продукт, выбрать подходящих клиентов, найти путь
к человеку, который отвечает за нужную задачу, подготовить персональные письма
и презентации, выполнить разрешённую отправку и разобрать ответы.
Цель кампании — содержательные разговоры и коммерческие возможности;
число отправок учитывается отдельно от результата.

## Что добавлено в 0.2.0

- Карта выходов к ответственному: прямой рабочий контакт, профильный отдел,
  рекомендация через знакомого или партнёра, официальный канал.
- Происхождение каждой записи, проверка роли и актуальности контакта,
  дубли компаний и групп, история касаний, отказы и владелец отношений.
- Границы самостоятельной работы: сохранение уже согласованных решений,
  отдельный учёт новых писем, ответов и напоминаний, объёма и срока разрешения.
- Проверка загрузки всего почтового аккаунта и разбор неопределённой попытки
  отправки до любого повтора.
- Связанный комплект «адресат → письмо → вложения» и локальная проверка файлов
  по SHA-256 с отпечатком точной версии комплекта.
- СБИС / Saby Profile как возможный дополнительный источник российских
  контрагентов и контактов. Навык предлагает оценить пользу и действующий
  доступ; покупка не обязательна.
- Формы карточки кандидата, паспорта кампании и manifest комплекта.

Полный список изменений: [CHANGELOG.md](CHANGELOG.md).

## Состав комплекта

Общий навык находится в `skills/b2b-outreach/`:

- `SKILL.md` — основной порядок работы.
- `references/` — интервью, исследования, контакты и пути к ответственному,
  письма, презентации, отправка, ответы, платные источники и проверка комплекта.
- `assets/` — пустые формы и явно вымышленные примеры.
- `scripts/check_package.py` — необязательный локальный помощник на Python.
- `agents/openai.yaml` — дополнительное оформление навыка для Codex.

Для установки плагина используются корневой `plugin.json` и каталог
`.agents/plugins/marketplace.json` в Codex; `.claude-plugin/plugin.json`
и `.claude-plugin/marketplace.json` в Claude Code. Обе программы получают
одну и ту же папку навыка `skills/b2b-outreach/`.

## Установка плагина из GitHub

Выберите установку плагина **или** отдельного навыка ниже. Если старая копия
навыка уже установлена, сначала сохраните собственные правки и выберите одну
активную копию, чтобы программа не видела два одинаковых навыка.

### Codex

В терминале с установленным Codex CLI добавьте каталог репозитория:

```bash
codex plugin marketplace add matvejchev-stack/b2b-outreach --ref main
codex plugin marketplace list
```

Перезапустите настольное приложение. Откройте каталог плагинов, выберите источник
**Matveychev B2B**, затем плагин **B2B-кампании: поиск, письма и презентации**
(`b2b-outreach`) и установите его. Имя источника в конфигурации — `matveychev-b2b`.
Эти действия описаны в [официальной документации OpenAI](https://developers.openai.com/plugins/build/plugins).

В новом чате попросите использовать навык B2B-кампаний из плагина
`b2b-outreach` и дайте сайт или описание продукта.

### Claude Code

В терминале с установленным Claude Code:

```bash
claude plugin marketplace add matvejchev-stack/b2b-outreach
claude plugin install b2b-outreach@matveychev-b2b
claude plugin list
```

После установки в новой сессии:

```text
/b2b-outreach:b2b-outreach Мой продукт: [описание или сайт].
Хотим клиентов в [страны]. Изучи материалы и проведи интервью.
Затем подготовим персональные письма и презентации с нашими контактами.
```

Команды и пространство имён навыков описаны в
[официальной инструкции Claude Code](https://code.claude.com/docs/en/plugin-marketplaces).
Структура manifest сверена с
[справочником плагинов](https://code.claude.com/docs/en/plugins-reference).

Это собственный каталог автора в GitHub. Установка из него не означает
публикацию в глобальном каталоге OpenAI или Anthropic.

## Инструменты и данные

Поиск, документы, презентации, таблицы и почта берутся из доступных инструментов
пользователя. Навык не переносит аккаунты автора и не подключает платные
сервисы автоматически. Без почты он готовит пакет для ручной отправки;
при отсутствии поиска или рендеринга файлов прямо называет ограничение.
Внешняя отправка выполняется только в пределах явного разрешения пользователя.

Для российской кампании навык предлагает рассмотреть СБИС / Saby Profile,
если сервис может помочь с отбором компаний или поиском рабочего входа.
Условия тарифа, доступные данные и права выгрузки проверяются перед использованием;
наличие адреса не доказывает роль человека, интерес или бюджет.
Подробнее: [платные источники](skills/b2b-outreach/references/paid-sources.md).

В комплекте нет реальных клиентских баз, личных контактов, переписки,
ключей доступа и условий сделок. Данные конкретной кампании храните отдельно.

## Локальная проверка комплекта

Помощник требует Python 3.9+ и использует только стандартную библиотеку.
Он не обращается к сети, не отправляет письма и не меняет manifest или файлы.
Из корня установленного навыка:

```bash
python3 scripts/check_package.py /path/to/package/manifest.json --account sender@example.invalid --send-date 2026-11-17
```

Подставьте свой manifest, реальный аккаунт и фактическую локальную дату
планируемой отправки. Пример manifest в `assets/package.example.json` — заготовка;
без собственных файлов и контрольных сумм он не проходит проверку.

Скрипт сверяет файлы по SHA-256, метаданные получателя, язык, состав вложений
и заявленную дату официального письма, затем выдаёт отпечаток комплекта.
Повторный запуск с `--expected-digest` сравнивает его с версией, которую
проверили ранее. Порядок: [проверка комплекта](skills/b2b-outreach/references/package-check.md).

Результат `integrity_checked` не подтверждает смысл и оформление PDF, историю
отношений, разрешение, свободную квоту или доставку. Эти проверки выполняются
отдельно. Скрипт также не координирует параллельные отправки из одного аккаунта.

## Статус проверки

При подготовке 0.2.0 пройдены **17 локальных тестов** помощника на стандартной
библиотеке Python. Они проверяют изменение файлов и отпечатка, неверного
отправителя, нескольких получателей, состав вложений, дату и метаданные,
выход путей за каталог, исходный тред ответа, синтаксис адресов, UTF-8
тела и ошибочный ввод. Независимо проверен учебный сценарий продолжения
кампании с отпиской, неподтверждённым адресом, рекомендацией и неизвестной попыткой.
Повторить из корня репозитория:

```bash
python3 scripts/validate_release.py
python3 -m unittest discover -s tests -v
```

Первая команда проверяет согласованность версий, структуру manifest и каталогов,
JSON и локальные ссылки. Вторая запускает тесты помощника.

Manifest и инструкции установки сверены с указанной официальной документацией.
Реальная установка новых manifest плагина в Codex, установка и запуск в
Claude Code, а также полный цикл живого поиска, создания презентаций и отправки
в рамках 0.2.0 **не проверены**. Локальные тесты подтверждают поведение помощника,
а не коммерческую эффективность кампании или работу внешних сервисов.

## Обновления

Изменение репозитория в GitHub само по себе не обновляет установленные копии.
Для плагина отдельно обновите источник и установленную версию средствами своей
программы; проверьте версию после обновления. В Codex список источников можно
обновить командой `codex plugin marketplace upgrade matveychev-b2b`, после чего
нужно проверить установленный плагин в каталоге. Для отдельного навыка сравните
версии, сохраните резервную копию вне каталогов навыков и перенесите весь каталог
с сохранением собственных правок.
