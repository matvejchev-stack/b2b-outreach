# B2B-кампании для Codex и Claude Code

Автор: Александр Матвейчев. Версия комплекта: 0.1.1.

Навык помогает предпринимателю разобрать продукт, выбрать страны и сегменты,
найти компании и нужных людей, подготовить персональные письма и презентации,
выполнить разрешённую отправку и разобрать ответы.

## Один комплект для двух программ

Общая папка навыка — `skills/b2b-outreach/`. Внутри находятся `SKILL.md`,
сценарий интервью, правила исследования, работы с контактами, подготовки
презентаций, отправки и учёта ответов, а также форма паспорта кампании.

Навык использует общий формат Agent Skills. `agents/openai.yaml` содержит
дополнительное оформление для Codex; для работы в Claude Code оно не требуется.
Файл `plugin.json` — дополнительная упаковка для возможной публикации плагина,
для установки отдельного навыка он не нужен.

## Быстрая установка по ссылке

Скопируйте в свою программу соответствующий текст.

**Codex:**

```text
Установи навык с помощью skill-installer из
https://github.com/matvejchev-stack/b2b-outreach/tree/main/skills/b2b-outreach
Сохрани все вложенные references, assets и agents.
Если навык уже установлен, сравни версии и не перезаписывай его молча.
После установки проверь доступность всех файлов.
```

**Claude Code:**

```text
Скачай репозиторий https://github.com/matvejchev-stack/b2b-outreach
и установи всю папку skills/b2b-outreach в ~/.claude/skills/b2b-outreach/.
Сначала прочитай инструкции. Сохрани вложенные references и assets.
Если навык уже установлен, сравни версии и не перезаписывай его молча.
После установки проверь доступность всех файлов.
```

## Установка из скачанного архива в Codex

Скачайте и распакуйте комплект, дайте Codex доступ к папке и напишите:

```text
Установи навык из skills/b2b-outreach этого комплекта в мои личные навыки Codex.
Сначала прочитай инструкции. Скопируй всю папку с references, assets и agents.
Если навык с таким именем уже есть, сравни версии и не перезаписывай его молча.
После установки проверь, что SKILL.md и все вспомогательные файлы доступны.
```

При передаче через GitHub вместо скачивания можно дать Codex ссылку
на папку навыка и попросить встроенный skill-installer установить его оттуда.

Запуск после установки:

```text
Используй $b2b-outreach. Мой продукт: [описание или сайт].
Хотим клиентов в [страны]. Изучи материалы и проведи интервью.
Затем подготовим персональные письма и презентации с нашими контактами.
```

## Установка из скачанного архива в Claude Code

Скачайте и распакуйте комплект, откройте его папку в Claude Code и напишите:

```text
Установи навык из skills/b2b-outreach этого комплекта в ~/.claude/skills/b2b-outreach/.
Сначала прочитай инструкции. Скопируй всю папку с references и assets.
Если навык с таким именем уже есть, сравни версии и не перезаписывай его молча.
После установки проверь, что SKILL.md и все вспомогательные файлы доступны.
```

Запуск после установки:

```text
/b2b-outreach Мой продукт: [описание или сайт]. Хотим клиентов в [страны].
Изучи материалы и проведи интервью. Затем подготовим персональные письма
и презентации с нашими контактами.
```

Личные навыки Claude Code хранятся в `~/.claude/skills/`; для установки только
в одном проекте используется `.claude/skills/` внутри проекта.
При передаче через GitHub можно поручить Claude Code скачать репозиторий
и установить из него именно папку `skills/b2b-outreach/`.

## Что нужно для работы

Поиск, документы, презентации, таблицы и почта берутся из доступных инструментов
самого пользователя. Навык не переносит аккаунты автора и не устанавливает
сторонние платные сервисы автоматически. Без почты готовит пакет для ручной
отправки. При отсутствии поиска или генератора презентаций прямо называет
ограничение. Отправка требует разрешения пользователя в пределах кампании.

Реальных клиентских баз, контактов, переписки и условий сделок в комплекте нет.

## Статус проверки

Проверены структура навыка, относительные ссылки, целостность ZIP и два
учебных сценария: отбор адресатов с отказами и неопределённой отправкой;
интервью для двух стран при противоречивых исходных данных.

Навык установлен в Codex автора. Формат и инструкции установки для Claude Code
сверены с официальной документацией; запуск внутри Claude Code не проверялся.
Полный цикл реального поиска, создания презентаций и отправки ещё не проверен.
